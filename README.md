# Stock Market Analysis Dashboard

## Project Overview

A Python-based stock market analysis dashboard developed as part of my FinTech learning journey.

The application allows users to explore historical stock prices, compare stock performance and analyse basic financial metrics through an interactive web interface.

## Features

- Stock price tracking
- Interactive historical price charts
- Daily percentage changes
- Period returns
- Annualised volatility calculations
- Highest and lowest closing prices
- Comparison of Apple, NVIDIA and Tesla
- Five-stock market watchlist

## Technologies Used

- Python
- Streamlit
- Yahoo Finance (`yfinance`)
- Pandas
- Plotly

## How to Run

1. Install Python.
2. Install the required libraries:

   `py -m pip install -r stock_dashboard/requirements.txt`

3. Launch the dashboard:

   `py -m streamlit run stock_dashboard/app.py`

4. Open `http://localhost:8501` in your browser.
